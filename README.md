# BioBanco Digital

Primeira versão funcional do site **BioBanco Digital de Organismos Não Alvo em Sistemas Agrícolas**.

## Arquivos principais
- `index.html`
- `style.css`
- `app.js`
- `dados/registros.json` — 307 registros
- `dados/culturas.json`
- `dados/indices.json`

## Fotos
Coloque somente as imagens finais com fundo branco:

- `imagens/algodao/` → A1, A2...
- `imagens/cebola/` → CEB1, CEB2...
- `imagens/cenoura/` → CEN1, CEN2...
- `imagens/milho/` → M1, M2...
- `imagens/soja/` → S1, S2...
- `imagens/tomate/` → T1, T2...

O site reconhece automaticamente `.jpg`, `.jpeg`, `.png` e `.webp`.

## GitHub Pages
1. No repositório `biobanco-cebio/biobanco-digital`, clique em **Add file > Upload files**.
2. Envie o conteúdo desta pasta mantendo as subpastas.
3. Clique em **Commit changes**.
4. Vá a **Settings > Pages**.
5. Em **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` (ou a branch principal)
   - Folder: `/(root)`
6. Clique em **Save**.

## Nota científica
Os índices apresentados no site têm caráter exploratório e representam diversidade taxonômica operacional dos registros disponíveis no BioBanco.
